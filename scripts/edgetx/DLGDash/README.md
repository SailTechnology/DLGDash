# DLGDash v1.0 使用说明

作者：Sail。面向 DLG / F3K 的 EdgeTX 飞行仪表。

第一次安装请先看包内 **INSTALL-BEGINNER.md**，或打开[图文新手安装教程](https://github.com/SailTechnology/DLGDash/blob/codex/v1.0/docs/INSTALL-BEGINNER.md)。本文是完整功能与设置参考。

这是第一个公开版本，运行时版本号为 1.0.0。此前 PA01 私测版的 2.0.x 是内部编号，不表示公开版本退回旧功能；原有 DLG2/3/4/5 插件配置继续兼容。

## 2. 安全边界

插件不改混控、输出、舵机方向、行程、飞行模式、逻辑开关、原生计时器、遥测校准或射频参数，不刷任何固件。只读取这些数据；保存文件仅在插件的 `profiles` 和手动诊断的 `diagnostics` 目录。

在 EdgeTX 界面添加 Widget / 遥测屏本身会保存该模型的**显示页面配置**，这与修改飞行混控不同。自动安装脚本不修改模型文件，也不会替你添加页面。

先备份全部 `MODELS`、`RADIO` 和已有 DLGDash 配置。实验版本必须先在地面验收，确保断链、失控保护和原生告警仍正常。它是辅助显示，不可代替原生低压、失控保护或飞行安全判断。

## 3. 安装与升级

### 通用安装

1. 在 [Releases](https://github.com/SailTechnology/DLGDash/releases/tag/v1.0) 下载 **DLGDash-v1.0.zip**。GitHub 自动提供的 Source code ZIP 是开发源码，不是直接安装包。
2. 遥控器进入 USB 存储模式，确认内容盘根目录有 `RADIO`、`MODELS`、`SCRIPTS`，不要向固件/引导盘复制文件。
3. 把全体模型和遥控器配置备份到电脑。升级时另备份 `WIDGETS/DLGDash`、已有 `DLGSetup.lua` 和 `DLG.lua`。
4. 解压后，将包内 **SD 文件夹里面的内容**合并到内容盘根目录。不能形成 `SD/SD` 或 `WIDGETS/DLGDash/DLGDash`。
5. 只覆盖 DLGDash 自身的代码和语言资源，保留自己原有的 `profiles`。如有同名旧 `.luac`，确认备份后移除对应缓存，让固件重新编译。不要删除别的 Lua 脚本。
6. 安全弹出磁盘，退出 USB 模式并重新启动遥控器。

安装后的结构：

```text
/WIDGETS/DLGDash/
  main.lua
  profile.lua
  core.lua
  draw.lua
  settings.lua
  locale.lua
  diagnostics.lua
  mono-ui.lua
  mono-settings.lua
  lang/
    zh.lua, mono.lua, OFL.txt
    zh/*.png
    mono/*.bmp
  profiles/                 首次保存时生成，不随分享包分发
/SCRIPTS/TOOLS/DLGSetup.lua
/SCRIPTS/TELEMETRY/DLG.lua
```

黑白屏也必须复制 `WIDGETS/DLGDash` 这个公共代码目录，但它不会作为 Widget 运行。彩屏不需要启用 `DLG.lua`。

### PA01 / V16：添加主屏

在 EdgeTX 的屏幕布局设置里选择单一区域的 1×1 布局，添加 **DLGDash**。PA01 建议尽量隐藏不必要的原生装饰栏；V16 对 480×272 全屏及 480×232/240/252 主屏区域做了测试。小区域会提示使用更大区域，不把仪表硬挤进去。

普通主屏右上角显示作者 **Sail**。进入 Widget 全屏后，此位置变成 **SET**，可点按或按确认键进入设置；普通 Widget 状态通常收不到按键事件。也可从系统工具页打开 **DLG Setup**。

### X9D / GX12：添加遥测屏

在当前模型的 **Display / 显示** 页面选择一个空闲屏幕，将类型改为 **Script**，文件选 **DLG**。不同固件翻译可能把该项放在遥测显示设置。长按 PAGE 或用该机型的原生遥测快捷键进入遥测屏。

黑白屏不是彩屏 Widget；不能使用“添加 Widget”来安装。文件名 `DLG.lua` 满足 EdgeTX 遥测脚本不超过六个字符的限制。[官方遥测脚本说明](https://luadoc.edgetx.org/overview/script-types/telemetry-scripts)

仪表内使用滚轮 / 加减键切换“飞行总览”和“舵量”两页，按确认键打开设置。保留原生 PAGE / EXIT 的遥测页面导航。总览显示大计时器、电压、当前高度 A、发射高度 L、升降速度及右下角曲线；A/L 单位为米，B 表示提示音触发已启用，M 表示未启用或静音。舵量页同时显示四路或六路固定字号百分比及位置条。

受 64 像素高度限制，黑白屏不把六路舵量与大计时器硬放在一页；曲线为自适应纵轴的趋势图，没有彩屏的完整刻度。主飞行页使用简短英文/符号，设置支持中文和英文。

### 可选：PowerShell 安全安装

仅面向会使用命令行的人，普通用户用上面的复制方法即可。需要 PowerShell 7；在源码的 `scripts/edgetx/DLGDash` 目录运行，盘符和备份目录换成实际值：

```powershell
./Backup-Radio.ps1 -CardRoot H:\ -BackupRoot D:\RadioBackups
./Install-DLGDash.ps1 -CardRoot H:\ -BackupDirectory D:\RadioBackups\实际生成的备份目录
```

V16、X9D、GX12 还需显式加 `-AllowExperimental`。安装器检查机型、备份完整性和当前盘是否与备份一致；逐文件校验安装结果，再校验所有模型、RADIO 和已有 profiles 未变。它只会移除已备份且哈希一致的同名编译缓存。备份保存在本地，不上传 GitHub。

## 4. 第一次使用：逐个模型设置

1. 先确认当前模型，进入 LANGUAGE 选择 English / Chinese，保存。安装包同时包含两种语言，不必更换固件或语言包文件。
2. BATTERY 选择实际电池电压源，通常是 `RxBt`。对照底部实时读数与原生遥测页。
3. TELEMETRY 选择高度 `Alt`、垂直速度 `VSpd` 以及原有 Timer 1/2/3。没有高度传感器就不会有真实高度曲线；没有垂直速度源可选 None，由高度变化估算。
4. LAUNCH 选择发射爬升结束前所处模式，例如 Zoom；设置退出后的延迟和结算方法。不要只按别人模型的模式编号照抄。
5. SERVOS 选择四舵机或六舵机，把 LA / RA / ELE / RUD / LF / RF 映射到自己的输出通道，在地面逐个核对。
6. GRAPH 选择曲线窗口、间隔和平滑参数，绑定自己的 Preset / 清曲线按钮及有效位置。
7. AUDIO 绑定自己的升降提示音按钮；TONE SETTINGS 调节音量、音调、节奏，保存并退出设置后地面试听。

**V16、X9D、GX12 新配置的声音和清曲线开关默认关闭**，需要自行绑定；PA01 新配置沿用 SF 高位声音、SE 高位清曲线的旧默认。已有保存配置不覆盖。默认通道 CH1～CH6 只是初始映射，不保证符合接线。

彩屏设置可触摸或滚轮操作；底部 `<`、`>` 翻页，`Save` 保存，`Exit` 返回。黑白屏每次显示一个字段，滚轮/加减依次经过该页字段和底部四个动作，确认进入选择或执行动作；PAGE 可翻设置页。选择列表用滚轮/加减改变选项，确认采用，EXIT 取消。中文页签过长或系统名称无法显示时会使用截短英文/问号回退，不影响存储的原名。

有未保存修改时，第一次退出提示，再次退出才丢弃。设置期间升降提示音暂停，避免菜单操作时误响。

## 6. 电压、串数与 HV

彩屏大号数字为当前实测源电压，小号 FULL / 满充为参考；黑白屏合写为 `8.1V/8.4V`。显示当前电压，不显示电量百分比，不套电压偏移来“修正”传感器。

自动识别只能推断 1S / 2S；5.2V 等不明确情况提示 SET PACK。电芯表支持将有效单节求和。BEC 输出并不等于电池端电压，不能据此识别原电池。

HV 与普通 LiPo 放电后电压重叠，无法仅凭电压可靠区分。自动模式在连续有效读数高于 4.24V/节时识别 HV；否则显示 AUTO?，暂用 4.20V/节。已知电池类型应手动选择，HV 满充参考是 4.35V/节、2S 为 8.70V。断链至少两秒后自动识别重新判断。

**满充参考不是当前电压，不是充电控制，也不能证明接收机/舵机支持 HV。** 电池直供前必须核对接收机和舵机允许电压。

## 7. Zoom 结束与发射高度

例如选择 FM2 Zoom、延迟 0.8 秒：

- 进入 FM2 开始新一轮发射记录。
- 退出 FM2 后等待 0.8 秒；等待期间显示 WAIT。
- “延迟结束值”取该时刻最新有效高度；“阶段峰值”取进入 FM2 至延迟结束间的最高有效读数。
- 下一次进入 FM2 才开始下一轮，不因普通计时器变化而清掉结果。

结算时高度无效则该次不结算，不能用后来恢复的读数补填。峰值还要求完整观察整个阶段：中途失去遥测、脚本暂停或在 Zoom 中途启动，不能声称得到完整峰值。高度是传感器当前基准下的高度，插件不自动重置高度传感器；地面零点应先在原生遥测功能中核对。

## 8. 曲线、慢回传与 Preset

曲线最多约 120 个采样点。实际间隔为“用户选择的间隔”和“窗口 / 120”的较大值，例如 90 秒窗口选择 0.1 秒，实际约 0.75 秒；不是遥测无线包率。

平滑使用一阶低通，仅影响曲线，不改当前高度数字、发射高度或电压，不生成真实传感器没有测到的峰值。平滑越大，曲线越缓、显示延迟越大。有效历史点之间连线，真正缺失的数据不跨空段连线。

慢速回传的正常包间隔仍显示有效值，不再因 `isFresh=false` 反复显示“无高度”；只有 `isCurrent=false` 等真正失效时才隐藏数据和停音。没有 VSpd 时根据可观察到的高度更新间隔求导，不把每次屏幕刷新当成新测量。

Preset 按下清一次，按住保持空图，松开等待 0.5 秒后重新记录。只清插件曲线和派生速度，不清原生计时器、遥测或已结算的发射高度。如果同一个物理按钮还绑定了原生遥测清零，那是模型原来的行为，不由插件修改。

## 9. ELRS 回传率要求

> **在保持控制链路可靠、接收机兼容的前提下，ELRS 遥测回传频率应尽可能高。**

这里强调的是**遥测回传**，不是盲目把发射包率拉到最大：

- `Packet Rate` 是上行控制包率；`Telem Ratio` 决定遥测时隙比例。相同包率下，1:8 比 1:32 分配更频繁的遥测机会。
- 避免关闭遥测的 Off，或会在特定状态停遥测的 Race 配置；具体可选项以当前 ELRS 版本和接收机支持为准。
- 高包率可能降低链路灵敏度/距离余量，不能为曲线流畅牺牲控制可靠性。
- **只在地面调整，不得飞行中修改 Packet Rate**，修改会触发重新同步/断连。调整后做距离和失控保护测试。
- 遥测时隙仍需复用链路统计和传感器数据，所以不能把“包率 ÷ 比例”当成 Alt 每秒必到次数。传感器采样率也可能是瓶颈。
- 插件不读取或修改 ELRS 参数；平滑不能消除真实采样延迟，不能还原两次回传之间缺失的测量。

见 [ELRS 官方包率与遥测比例说明](https://www.expresslrs.org/quick-start/transmitters/lua-howto/#packet-rate-and-telemetry-ratio)及[遥测带宽说明](https://www.expresslrs.org/info/telem-bandwidth/)。相同提醒也写在 `core.lua` 的遥测读取注释中。

## 10. 电压诊断

如果插件和原生遥测不同，先对照**同一时刻、同一个源**，不要拿满充参考或历史最大值相比：

1. 电池页看选中的电压源和实时读数。彩屏会并列显示“所选源 / 直接 RxBt”。
2. 第 10 页查看电压诊断。彩屏显示所选源、RxBt 按名、按 ID/旧接口和最小/最大值；黑白屏简化显示所选源、RxBt、源 ID。
3. 在地面接收机连接状态下选择 Record，保持本页约 6 秒。每 0.25 秒一组，共 24 组。
4. 等待保存成功后再进入 USB 存储模式，读取 `/WIDGETS/DLGDash/diagnostics/` 中新生成的 CSV。

两种屏幕记录同一套完整字段：所选名称/ID/单位/有效性、按名和按 ID 的电压、旧 getValue 对照、最小/最大值及遥控器自身电压。这是 EdgeTX **解码后的数据**，不是原始无线报文。

USB 存储连接只能读取文件，不能从 SD 配置直接读到实时 RxBt。若插件与原生页一致、均与万用表不同，应继续检查电池供电路径、测量位置和接收机遥测/校准；本插件不修正 ER6GV 的 ADC，也不会擅自重刷固件。离开诊断页或换模型取消未完成的记录。

## 11. 配置独立保存、备份与回退

配置保存在 `/WIDGETS/DLGDash/profiles/<radio>_<model-file>.a/.b`，按遥控器型号和模型文件名隔离。两模型显示名相同但文件不同，不会串配置；同一型号的两台遥控器若复制了相同文件和 profiles，则视为相同配置，不绑定设备序列号。

两槽交替写入，带校验和和关闭后回读；写入失败保留上次有效槽。安装不迁移文件，读取旧格式时只在内存补齐新增默认，用户保存后才写 DLG5。复制原生模型到新文件后，需要在新模型单独设置插件。

升级保留自己已有 profiles。回退先备份现在的状态，再恢复旧版插件目录和它对应的 profiles；单独恢复旧 Lua 但沿用不受支持的新格式可能失去设置。无需为了回退插件刷固件或恢复全体模型。

分享给别人只发干净发布包，不发 `MODELS`、`RADIO`、个人 `profiles` 或 `diagnostics`。对方必须核对自己模型的传感器、飞行模式、四/六路通道和按钮。

## 12. 常见问题

| 现象 | 检查 |
| --- | --- |
| 找不到 DLGDash | 彩屏确认路径和 main.lua；黑白屏去 Display 选 Script / DLG，不找 Widget |
| 缺少中文、部分英文回退 | 确认整个 lang 目录完整；过长标签会回退，不支持任意系统名称的中文字库 |
| 不显示电压/高度 | 先在原生遥测页确认该源存在且有效，再检查插件映射和单位 |
| 电压闪或无高度 | 检查真实链路/传感器有效性；正常慢包本版会保留，真正失效不能强行保持假数据 |
| 曲线一直空白 | 检查是否把常为真的源绑成清零，或按钮位置一直有效 |
| 声音不响 | 检查 VSpd/Alt、触发源和位置、静区、静音及系统音量；设置页本来静音 |
| 声音重复 | 原生 Vario 可能也已绑定；用户自行选择需要的告警，插件不替你删除原有功能 |
| 发射高度一直未结算 | 确认实际进入并退出所选模式，等待设定延迟，检查期间是否断链 |
| 舵量方向/通道不对 | 调整插件映射；不要为显示问题反转模型输出 |
| profile 字符串报错 | 本版不依赖字符串元表；确认更新全部 Lua 并清理已备份的同名 luac |
| 设置保存失败 | 检查磁盘空间、只读状态、完整路径和当前模型文件名；不要飞行中尝试修复存储 |
| Lua 内存不足 | 退出其他不必要的脚本，反馈机型/EdgeTX 版本/同时运行脚本；黑白屏内存仍需实机验收 |

## 13. 验证与开发

普通安装无需 Node、Python 或编译固件。开发测试需要 Node.js 22 或更高、pnpm，以及首次下载官方参考字体时联网。

在 `scripts/edgetx/DLGDash/tests`：

```sh
pnpm install --frozen-lockfile
pnpm test
```

测试涵盖 PA01、V16、X9D、GX12，禁用 Lua 字符串元表，限制可访问的模型 API，模拟配置损坏/迁移、传感器有效性、慢包、发射结算、四/六舵机、提示音和设置。原生字体从 EdgeTX v2.11.3 官方源码下载并验证 SHA-256；参考源码/字体不进安装包。

渲染测试直接执行 Lua 绘制调用，用固件原生字体/位图检查越界和文字重叠，不是手工制作的概念图。结果输出到 `output/DLGDash-v1.0/verification-<radio>`；关键回调以 20,000 条 Lua 指令作保守检查。它们不等于完整 EdgeTX 模拟器，也不能证明实机运行内存、按键码、声音响度或射频更新率。

中文资源来自 `tests/zh.json` 和 Noto Sans SC；重建需要 `@napi-rs/canvas` 0.1.100，通过 `DLG_CN_FONT` 指定 Noto 字体，运行 `pnpm build:language`。彩屏 PNG 有 14/17/21 三种行高；黑白屏使用更细的 14 像素行高 BMP，每片不超过 64 像素宽，选择列表每屏两项，遵守旧固件 drawPixmap 限制。常规测试直接使用已生成资源，不需要字体生成器。

早期电脑黑白预览曾把原生字体的 `0xff` 压缩占位列误画为黑线，导致小数点/数字看起来粘连；渲染器现按固件 FIXEDWIDTH 规则将这些列留白，并增加像素回归测试。文档提供整数倍放大图，不用模糊插值。这是预览修正，不是接收机或显示屏硬件故障诊断。

打包在源码目录用 PowerShell 7 运行：

```powershell
./Build-Package.ps1
./tests/install-smoke.ps1
```

打包使用全新暂存目录，仅复制运行代码/语言包/说明，拒绝个人目录和 luac，压缩后逐项校验哈希。默认生成 `output/DLGDash-v1.0/DLGDash-v1.0.zip`。安装冒烟测试使用电脑临时目录模拟内容盘，不连接真实遥控器。

## 14. 四台遥控器地面验收清单

- 启动无 Lua 错误，切换页面和模型无串配置。
- 舵量与原生输出一致，99→100→150 字号不跳，四/六路均可读取。
- 设置中英文切换、长名称选择、保存、退出和断电重启正常。
- 原生 RxBt/Alt 与插件原始值对照一致，满充参考未被误认为当前值。
- 每种模式退出、延迟、重复发射、无高度时的结算符合预期。
- Preset 按下清图、按住不重绘、松开后恢复。
- 慢回传不误闪，真正断连留空段且停音。
- 声音绑定、音量、上升/下降音调和原生报警共存正常。
- 试用期间没有脚本内存/执行超限；与原有灯效或其他脚本同时运行也需核对。
- 完成地面验收之后，再由操作者决定受控飞行验证。
