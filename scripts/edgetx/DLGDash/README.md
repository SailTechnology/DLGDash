# DLGDash 设置与使用

第一次安装请先按安装包内的 **INSTALL-BEGINNER.md** 操作。本页用于安装后查找参数。

当前兼容测试版为 [v1.0.1-beta.4](https://github.com/SailTechnology/DLGDash/releases/tag/v1.0.1-beta.4)。PA01、V16、V12 下载 DLGDash-Color-v1.0.1-beta.4.zip；X9D、GX12、Zorro、T14 下载 DLGDash-Monochrome-v1.0.1-beta.4.zip。本版包含 V16 绘图、黑白屏内存和保存兼容修复，仍需地面验证，不需要先升级固件。

T14 使用黑白屏包，包含设置内存与保存修复、EdgeTX 2.10 独立音量选项；按 INSTALL-MONO.md 完成地面检查。

V12 新增 320×240、滚轮按键实验适配，请按彩屏包内 `INSTALL-V12.md` 安装。无需 App Mode，不需要触摸操作。V12 尚未完成实机验收。黑白屏包已包含缺少 `table` 库时的保存修复。

## 打开设置

- 彩屏：进入 DLGDash 全屏，点 **SET** 或按确认键。
- 黑白屏：进入 DLG 遥测页，按确认键。
- 所有机型：系统 **TOOLS / 工具 → DLG Setup**。

滚轮移动，确认键进入或采用选项，返回键取消。设置页底部 `<`、`>` 翻页，Save 保存，Exit 退出。有星号时表示尚未保存；连续两次退出会放弃修改。

**每个模型单独设置。** 换飞机后重新核对电压源、发射模式、舵机通道和按钮。

## 主界面怎么看

| 显示 | 含义 |
| --- | --- |
| 大计时器 | 所选原生计时器的当前值；仍由原来的模型按钮控制 |
| 8.1V/8.4V | 当前电压 8.1V，满充参考 8.4V；不是电量百分比 |
| LAUNCH / L | 上一次发射结算高度，单位米 |
| ALTITUDE / A | 当前高度，单位米 |
| m/s | 垂直速度；正数上升，负数下降 |
| LA、RA、ELE、RUD、LF、RF | 左副翼、右副翼、升降、方向、左襟翼、右襟翼 |
| 右下曲线 | 最近一段时间的高度变化 |
| LINK / LNK | 当前有遥测连接；LOST / --- 表示没有有效连接 |
| BEEP / B | 提示音触发已启用；MUTE / M 为未启用或静音 |
| MIX | 旧固件显示的是混控量，不是最终舵机输出 |

黑白屏转动滚轮切换总览与舵量两页。没有传感器或没有回传时显示横线，不是安装失败。

黑白屏设置菜单会暂停插件的曲线采样、发射跟踪和提示音，退出后恢复；遥控器控制、原生计时器及原生遥测不暂停。曲线会断开未记录的时段，未完成的发射不会据此猜测高度。请在地面设置。

## 第 1 页：电池

| 选项 | 怎么选 |
| --- | --- |
| 电压源 / Voltage source | 选实际回传电池电压，通常为 RxBt。不要选 RxBt+、RxBt- 或遥控器自身电压 |
| 电池节数 / Pack cells | 已知规格时选 1S 或 2S；也可自动判断 |
| 电池类型 / Battery type | 普通 LiPo 每节满充 4.20V；HV 每节 4.35V；不确定时先核对电池标签 |

自动判断不能仅凭一块未满电电池可靠区分普通 LiPo 与 HV。出现 AUTO? 是类型尚不确定，SET PACK / CHECK PACK 时应手动核对规格。

页内实时电压应与原生同名源一致。若插件和原生均偏离万用表读数，应检查接收机测量、供电与校准，不要直接给插件加偏移。

选 HV 不会提高接收机和舵机的耐压，直供前须确认硬件额定值。

## 第 2 页：遥测与计时

| 选项 | 怎么选 |
| --- | --- |
| 高度源 / Altitude source | 通常为 Alt，按自己的传感器实际名称选择 |
| 垂直速度源 / Vario source | 通常为 VSpd；没有时可选 None，由高度变化估算 |
| 计时器 / Timer display | 选原本使用的 Timer 1、2 或 3 |
| 曲线平滑 / Curve smoothing | 可关闭或选 0.3、0.5、1、2、3 秒；先用 0.5 秒 |

平滑只让曲线更稳定，不会凭空增加回传频率，也不会改变原始高度的发射结算值。

## 第 3 页：发射高度

| 选项 | 怎么选 |
| --- | --- |
| 退出此模式 / Exit this mode | 选择自己爬升结束前的模式，通常为 Zoom；不要照抄别人的 FM 编号 |
| 退出后延迟 / Delay after exit | 0 到 10 秒，按 0.1 秒调整 |
| 高度结果 / Height result | “延迟结束值”取结算时的高度；“阶段峰值”取该模式内至延迟结束期间的最高高度 |

例如：选择 Zoom、延迟 0.5 秒、延迟结束值，离开 Zoom 后等待半秒再结算。

第一次先用 0 秒测试。切入所选模式会开始新一次发射；重新切入会重新计数。没有完整高度数据时可能不结算，请核对遥测后再测试。

## 第 4、5 页：四/六舵机与映射

1. 选择四舵机或六舵机。
2. 在原生通道监视器中确认各舵机对应的 CH。
3. 为 LA、RA、ELE、RUD 设置通道；六舵机再设置 LF、RF。
4. 不使用的通道选 Off。
5. 缓慢移动控制，检查数值与所选通道对应，再保存。

新版固件显示最终通道输出；旧版标为 **MIX**，表示限位和输出反向之前的混控量。它们都不是物理舵角。不要为了匹配显示修改模型的舵机方向或行程。

## 第 6 页：曲线与 Preset

| 选项 | 怎么选 |
| --- | --- |
| 时间窗口 / Time window | 30、60、90、120、180、300、600 秒；先用 90 秒 |
| 采样/实际 / Sample / effective | 请求 0.1 到 5 秒；右边显示实际绘图间隔，长窗口时可能自动变长 |
| 清曲线按钮 / Preset / clear button | 选择自己的按钮或开关，None 表示不绑定 |
| 清零有效位置 / Clear position | 按下时约 -100 选 Low，约 0 选 Middle，约 +100 选 High |

按下清空，按住保持空图，松开约 0.5 秒后恢复。这个动作只清插件曲线；原生计时器与遥测清零仍按模型原来的设置执行。

## 第 7、8 页：声音

| 选项 | 怎么选 |
| --- | --- |
| 按钮/开关 / Switch / button | 选择启用提示音的按钮，None 表示关闭绑定 |
| 有效位置 / Active position | 选择按下或打开时的位置 |
| 按钮行为 / Button behavior | “保持有效时”随开关状态启停；“按下切换”每按一次切换 |
| 速度静区 / Vario deadband | 0.1 到 2.0 m/s，小于此幅度不响；先用 0.3 |
| 音量 / Tone volume | 跟随系统、静音或独立档位；旧固件只支持前两项 |
| 上升基础音调 / Climb base pitch | 600、720、900、1100、1400 Hz |
| 下降基础音调 / Sink base pitch | 250、320、390、460、550 Hz |
| 节奏 / Beep cadence | 慢、标准、快 |

上升为较高短音，下降为较低长音。设置页内暂停提示音，保存退出后再试。旧固件音量在遥控器系统中调整，插件不会修改总音量。

## 第 9 页：中英文

选择 Chinese 或 English 后保存。设置按模型保存，不改变 EdgeTX 系统语言。

黑白仪表保留简短字母，设置页支持中文。部分旧版彩屏固件只显示英文；系统自定义的中文模式名或通道名不保证能完整显示。

## 第 10 页：电压核对

电压异常时在地面同时对照：所选电压源、RxBt 原生读数、飞机电池万用表读数。

需要记录时选择 Record / 记录，完成后显示“记录已保存”。把记录交给排错人员前先检查内容，不要直接公开上传整个模型备份。

## 旧固件使用注意

兼容测试包已加入 Zorro 的 EdgeTX 2.7.1 回退路径，也按较新的 EdgeTX 功能自动选择可用方式。尚未完成各版本真机验收，OpenTX / Ethos 不在已验证范围。

- 出现 MIX 时按混控量理解，不把它当最终舵机输出。
- 独立音量档位不可用时，使用遥控器总音量。
- 旧固件无法单独判断某个传感器是否过期。飞行前核对原生遥测；接收机断电后插件必须显示失联并停音。
- 旧固件保存需要安装包中的 profiles、diagnostics 文件夹，不能只复制 Lua 文件。
- 更换语言、翻完设置页、保存和重启都应在地面试过，并确认没有内存错误。

## ELRS 回传与飞行前检查

在控制链路可靠、接收机兼容的前提下，**尽可能提高有效遥测回传率**。调整 Packet Rate 和 Telem Ratio 前先记录原设置，参考 [ELRS 官方说明](https://www.expresslrs.org/quick-start/transmitters/lua-howto/#packet-rate-and-telemetry-ratio)。不要在飞行中改包率，不要把控制包率等同于高度回传率。

安装后先确认：全部模型仍在、原生混控与方向未变、电压与高度正确、计时同步、发射结算正确、按钮行为正确、失联停音。仪表不能代替原生告警和失控保护。

遇到安装、无数据、内存或保存错误，请查 INSTALL-BEGINNER.md 最后的排错表。
