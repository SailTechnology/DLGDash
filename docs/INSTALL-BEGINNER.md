# DLGDash v1.0 新手逐步安装教程

作者：Sail。按顺序完成本页，即使第一次安装 EdgeTX Lua 脚本，也不需要修改代码或刷固件。全部参数含义另见包内 README.md，或[在线功能说明](https://github.com/SailTechnology/DLGDash/blob/codex/v1.0/scripts/edgetx/DLGDash/README.md)。

在线直接在 GitHub 阅读即可；离线时用记事本也能打开 .md 阅读步骤，配图在旁边的 images 文件夹。支持 Markdown 预览的编辑器可把文字和图片一起显示。

**先说明验证范围：** PA01 是主开发机型；V16、X9D、GX12 是实验适配。本文的插件截图是执行 Lua 代码得到的离线模拟画面，数据不是实测，也不是原生系统菜单的照片。不同 EdgeTX 版本、语言和按键布局会使菜单名称/入口略有差别，找不到时按给出的菜单名称查找，不要试着刷固件“解决”。

## 第 0 步：确定走哪条安装路线

| 你的遥控器 | 你应该选择的路线 | 显示方式 |
| --- | --- | --- |
| PA01 | 第 5A 步 | 彩屏主屏 DLGDash Widget，320×240 |
| HelloRadio V16 | 第 5A 步 | 彩屏主屏 DLGDash Widget，480×272 |
| FrSky X9D / X9D Plus / Plus 2019 | 第 5B 步 | 黑白遥测屏 Script / DLG，212×64 |
| RadioMaster GX12 | 第 5B 步 | 黑白遥测屏 Script / DLG，128×64 |

不要把 V16 当成 V12。GX12 没有外置 TF 卡不影响本流程，它通过 USB 导出内置内容存储。其他遥控器不在本版首批范围。

打开遥控器的系统设置，找到 Version / 版本 / About / 关于，确认写的是 **EdgeTX**。本版以 **EdgeTX 2.11.3** 测试；ELRS 3.3.1 是射频部分的版本，不能代替 EdgeTX 版本。看到 OpenTX、Ethos 或 Lua 接口缺失时先停止安装并核对兼容性，本教程不包含固件升级。

完成标志：你已知道自己走 5A 还是 5B，并记下 EdgeTX 版本。

## 第 1 步：准备电脑和文件

1. 飞机放稳，接收机先断电。不要在飞行、拖曳或电机可意外启动的状态下进行安装。
2. 遥控器电量充足。准备一根能够传数据的 USB 线；只能充电的线不会出现内容盘。
3. 在电脑建立两个独立文件夹，例如“DLGDash下载”和“遥控器完整备份”。备份文件夹不要建在遥控器盘上。
4. 打开 [DLGDash v1.0 发布页](https://github.com/SailTechnology/DLGDash/releases/tag/v1.0)，展开 Assets / 资源。
5. 下载 **DLGDash-v1.0.zip**。不要选择 Source code (zip) 或 Source code (tar.gz)，它们是开发源码。
6. 在 Windows 对 ZIP 右键，选择“全部解压缩”，解压到“DLGDash下载”。不要直接在压缩包窗口内编辑文件。
7. 打开解压后的文件夹，你应该看到一个 **SD** 文件夹；打开它，应看到 WIDGETS、SCRIPTS、README.md、INSTALL-BEGINNER.md 等内容。

看不到 SD：先确认下载的是发布资源 DLGDash-v1.0.zip，不是 GitHub 源码包。不要凭文件夹名字猜测复制位置。

## 第 2 步：连接并找到正确的内容盘

1. 正常开机，在地面连接 USB 到电脑。
2. 遥控器询问 USB 模式时，选择 **USB Storage / USB 存储**。不要选 Joystick / 游戏控制器 / 模拟器模式。
3. 打开 Windows 文件资源管理器的“此电脑”，找到新出现的可移动盘。
4. 双击打开，检查根目录。正确内容盘通常能看到 **RADIO、MODELS、SCRIPTS、SOUNDS** 等文件夹，其中应有 `RADIO/radio.yml`。
5. 可能出现两个盘。只看到 FIRMWARE.BIN、EEPROM.BIN 等固件文件的盘不是本教程的复制目标；不要把插件放进去。
6. 如果 Windows 弹出“需要格式化才能使用”，选择**取消**，先检查连接和磁盘。安装插件不需要格式化。

下文以 `H:` 举例。你的盘可能是 E:、F: 或别的字母，**不要直接照抄 H:**。

没有盘：检查线缆是否支持数据、模式是否选对，以及是否插在支持数据的接口；重新连接后再看。不要修改 USB 驱动、引导程序或 ELRS 固件来碰运气。

## 第 3 步：先把所有模型备份到电脑

最稳妥的方式是复制整个内容盘。内容很多时至少备份下面这些，复制完成前不要覆盖任何脚本：

1. 在电脑“遥控器完整备份”里新建日期目录，例如 `PA01_安装DLGDash前_2026-09-07`。
2. 从遥控器内容盘把整个 **MODELS** 文件夹复制进去，不是只复制当前模型。
3. 把整个 **RADIO** 文件夹复制进去。
4. 如果存在 **WIDGETS/DLGDash**，把这个完整文件夹也按原路径复制进去，尤其是其中的 profiles。
5. 如果存在 **SCRIPTS/TOOLS/DLGSetup.lua** 或同名 `.luac`，一并备份。
6. 如果存在 **SCRIPTS/TELEMETRY/DLG.lua** 或同名 `.luac`，一并备份。
7. 如果根目录有 MODELS.zip，也一并复制；不要用它替代当前 MODELS 文件夹的备份。
8. 在电脑上打开备份，确认 MODELS 里确实有多个模型文件，RADIO 里有 radio.yml。对比复制前后的文件数和大小。

完成标志：备份在电脑本地，即使拔掉遥控器，也能在电脑找到它。不要把自己的备份发到公开 GitHub。

脚本作者没有远程修改模型的权限需求；安装代码只更新插件。以后在 EdgeTX 中添加显示页面会保存模型的“页面配置”，不会因此修改混控/输出参数。

## 第 4 步：复制插件，检查两条关键路径

1. 打开解压包中的 **SD** 文件夹。
2. 选中 SD **里面的内容**，复制到遥控器内容盘的根目录。
3. Windows 询问合并文件夹时允许合并。如果询问替换文件，只应涉及本次 DLGDash 插件及其说明资源。
4. 包里不应存在 MODELS 或 RADIO；如果某个下载包让你覆盖它们，停止并确认来源。
5. 升级用户保留自己的 `WIDGETS/DLGDash/profiles`。分享包不带 profiles，不会替你重置模型插件设置。
6. 打开内容盘，逐字检查：

```text
正确：H:/WIDGETS/DLGDash/main.lua
正确：H:/WIDGETS/DLGDash/core.lua
正确：H:/WIDGETS/DLGDash/lang/zh.lua
正确：H:/WIDGETS/DLGDash/lang/mono.lua
正确：H:/SCRIPTS/TOOLS/DLGSetup.lua
正确：H:/SCRIPTS/TELEMETRY/DLG.lua

错误：H:/SD/WIDGETS/DLGDash/main.lua
错误：H:/WIDGETS/DLGDash/DLGDash/main.lua
错误：H:/SCRIPTS/TELEMETRY/DLG.lua.txt
```

Windows 可在“查看 → 显示 → 文件扩展名”中显示真实后缀。不要只复制 main.lua，其他 Lua 和 lang 资源都是必需的。黑白屏同样需要 WIDGETS/DLGDash 这个公共目录。

### 升级用户：处理旧编译缓存

只有已装过旧版时才需要检查。Lua 旁边可能有同名 `.luac`，它是固件生成的编译缓存。

确认第 3 步备份完整后，只移除 **DLGDash 目录内与更新 Lua 同名的缓存**，以及已备份的 `DLGSetup.luac`、`SCRIPTS/TELEMETRY/DLG.luac`。不要搜索整张卡并删除所有 luac，不要删除 profiles，也不要删除其他插件。

不确定哪些能删，就先保留并使用完整使用说明中的备份/安装脚本，或反馈文件列表；不要清空整个 WIDGETS。

### 拔线前

1. 等 Windows 文件复制进度完全结束，关闭打开该盘文件的程序。
2. 在“此电脑”里右键遥控器内容盘，选择“弹出”，或使用任务栏“安全删除硬件”。
3. 提示成功后拔线，退出遥控器 USB 模式，并重新启动遥控器。

完成标志：遥控器正常进入原有模型，未出现 Lua 错误。此时还没有新增仪表页面是正常的，继续对应的第 5 步。

## 第 5A 步：PA01 / V16 添加彩屏主屏

1. 先确认当前模型是你要使用 DLGDash 的飞机。不要为了安装插件导入别人的模型。
2. 打开 EdgeTX 主导航，进入 **Screen Settings / 屏幕设置**。常见入口是主屏按确认键后选择屏幕设置，或 TELE 键；支持触摸的机型也可从 EdgeTX 图标菜单进入。
3. 选择要放仪表的 Main view / 主屏页。优先选择空白页；如果要替换已有页面，先拍照记下原布局和控件。
4. 找到 **Layout / 布局**，选择一个区域的 **1×1** 布局。
5. 找到 **Setup Widgets / 设置控件**，进入后应看到带边框的区域。
6. 选中这个大区域，选择 **DLGDash**。
7. 如果系统弹出 ToneSw、SwHigh、ToneMin、Timer 这四个简短选项，可先保持，再返回。更完整的映射在插件自己的设置里完成，不必反复改原生简短选项。
8. 返回主屏，应该看到大计时器和右上角 **Sail**。接收机没开机时电压/高度显示无数据是正常的，不能因此认定安装失败。
9. 如果区域太小，关闭本页不必要的 Top bar / Flight mode / Sliders / Trims 等显示装饰，或进入全屏。这里只改变页面显示，不改变摇杆、微调或混控本身。
10. 长按该 Widget 或选中后打开其菜单，选择 **Full screen / 全屏**。右上角 Sail 会切换为 **SET**。
11. 点 SET，或在全屏状态按确认键，应进入第一页 BATTERY。

另一条设置入口：系统的 TOOLS / 工具页选择 **DLG Setup**。如果工具页没有显示，可从 SD 文件管理找到 `SCRIPTS/TOOLS/DLGSetup.lua`，选择 Execute / 执行；不要执行 core.lua 或 profile.lua。

## 第 5B 步：X9D / GX12 添加黑白遥测屏

1. 确认当前模型。进入 **模型设置**，不要进入系统的 Radio Setup。
2. 用 PAGE / 翻页键找到 **DISPLAY / 显示** 页面。一般在 TELEMETRY / 遥测页面之后。
3. 选择一个空闲的 Screen / 屏幕，例如 Screen 1。如果这个位置已有原生数据页面，先记下内容，或选择另一个空闲位置。
4. 按确认键开始编辑屏幕类型，用滚轮或加减键把 Nums / Bars 等类型改成 **Script**，再次确认。
5. 移动到脚本文件名一栏，按确认，选择 **DLG**，再次确认。
6. 按返回退出模型设置，回到正常主屏。
7. 使用该机型原生遥测快捷键进入遥测屏。EdgeTX 2.11.3 的单 PAGE 键 X9D 使用长按 PAGE；GX12 若面板为 PAGE< / PAGE> 分开的翻页键，在正常主屏短按 PAGE<。若面板有专用 TELE 键则短按 TELE。必须先退出所有设置回到正常主屏再按；在设置里同一个键只是翻页。其他版本应核对对应手册的 Telemetry / View telemetry 快捷键。
8. 如果先看到别的遥测页面，用原生 PAGE 键切换到配置了 DLG 的那一页。
9. 应看到上方模式名、LNK/---、B/M、Sail，大计时器和右下角曲线。
10. 在 DLG 内转滚轮或按加减键，应在飞行总览与舵量页之间切换；按确认键进入设置。

找不到 DLG：重新检查 `SCRIPTS/TELEMETRY/DLG.lua`，以及是否误放进 TOOLS。不能只从文件管理“执行一下 DLG.lua”就认为添加成功，因为后台遥测脚本必须绑定到当前模型的 Display。

黑白屏不支持彩屏 Widget 菜单，也不会在普通原生主屏直接增加一块彩色仪表。

## 第 6 步：先学会选项、保存和退出

### 彩屏

点击字段进入选项列表，点选值；没有触摸时滚轮移动焦点、按确认。底部 `<` / `>` 翻设置页，Save 保存，Exit 退出。PAGE 键也可翻页。

### 黑白屏

每次显示一个字段，右侧 `1/4` 之类表示该页字段序号，不是电量。滚轮/加减依次选择字段，继续向下会经过底部 `<`、`>`、保存、退出四个动作。底部出现横线表示当前焦点在那里，按确认执行。

进入某个字段后，选项列表每屏显示两项，`>` 指向当前选项；继续转动会滚动列表。按确认采用，按返回取消。顶部 `8/10` 是设置页号。

![GX12 中文菜单](images/gx12-settings-large.png)

### 所有机型

改值后需要按 Save / 保存。出现星号代表有未保存修改。第一次退出未保存的设置会提示，再次退出才丢弃。保存后仍在设置里是正常的，再按退出返回仪表。

## 第 7 步：切换成中文

1. 从 BATTERY 第 1/10 页开始，用 `<` 向前翻两次，或 `>` 一直翻到 **LANGUAGE 第 9/10 页**。
2. 选择 Language，进入后选择 **Chinese** 并确认。
3. 底部选择 Save / 保存。
4. 退出并再次打开设置，检查仍是中文。

改回英文选择 English 即可。语言按模型保存，不会替系统菜单换语言。黑白主飞行页仍用简短英文/字母来节省空间，设置页使用中文位图；模式名、通道名等系统自定义名称不保证都能显示中文。

## 第 8 步：连接接收机，核对电压与高度

1. 遥控器先正常开机，确认当前模型和失控保护，再在地面给接收机供电。USB 存储模式下无法做实时遥测核对。
2. 先打开原生 TELEMETRY / 遥测页面，查看 RxBt、Alt、VSpd 是否有数据。已有传感器不要删除重搜。如果确实从未发现传感器，可在了解原生设置影响后使用 Discover new sensors / 发现新传感器，完成后停止发现。
3. 进入插件电池页，把 Voltage source / 电压源选为实际电池回传，例如 RxBt，而不是 RxBt+、RxBt- 或遥控器自身电压。
4. 看实时读数是否和原生同一个源一致。大号当前电压不是满充参考；`8.1V/8.4V` 表示当前 8.1V、参考满充 8.4V。
5. 已知是 2S 普通 LiPo，先明确选 2S、LiPo，减少自动识别的不确定性。HV 只有接收机和舵机允许相应电压时才考虑直供，选 HV 不会给硬件增加耐压。
6. 遥测与计时页选择 Alt / 高度和 VSpd / 垂直速度。没有 VSpd 可选 None；没有真实高度传感器就不会凭空产生高度。
7. 轻缓抬高、放低飞机，观察原生 Alt 和插件当前高度是否一起变化。几厘米变化可能小于传感器分辨率，不要为了看曲线快速甩动飞机。

完成标志：原生遥测与插件同源读数相符。若两者一致却与万用表不符，应查接收机供电/传感器测量，不要先给插件加偏移，更不要立即刷固件。

## 第 9 步：选对计时器、发射模式和舵量

1. 在遥测与计时页选择自己原本用的 Timer 1/2/3。用原有按钮启动/停止它，确认仪表跟随变化。插件本身不新建、不控制计时器。
2. 在原生模型里观察你发射爬升结束前的模式名，例如 Zoom。记下模式编号与名称，不要照搬别人的 FM2。
3. 插件发射页将“退出此模式”选成该模式。
4. 首次测试可先用 0 秒延迟、“延迟结束值”。在地面切入该模式再退出，确认产生结算；之后按自己的习惯设置延迟或阶段峰值。
5. 舵量页先选 4 servos / 四舵机 或 6 servos / 六舵机。
6. 对照原生 Channels Monitor / 通道监视器，逐个确认 LA 左副翼、RA 右副翼、ELE 升降、RUD 方向、LF/RF 左右襟翼分别在哪个 CH。
7. 在插件中设置对应 CH，然后缓慢操作摇杆、襟翼控制，确认数值一致。显示的是最终通道输出，不是物理舵角。
8. 如果显示方向不符合预期，先检查映射；不要为了让显示“好看”而反转真正的舵机输出。
9. 保存并退出。

## 第 10 步：绑定 Preset 清曲线

1. 进入高度曲线页，找到 Preset / clear button / 清曲线按钮。
2. 选自己实际用于 Preset 的开关或按钮源。不确定名称时，到原生开关监视器按一下对应按钮，确认是哪个源变化。
3. 根据按下时的值选择有效位置：Low 为约 -100，Middle 为约 0，High 为约 +100。不同人的接线/逻辑设置不同，不能全部照抄 High。
4. 保存、退出设置，在有高度回传的地面状态按该按钮。
5. 应看到曲线清空；按住应保持空图；松开约 0.5 秒后恢复新曲线。
6. 如果曲线一直空白，检查按钮源是否一直处于有效位置。暂时设 None 可以停用清曲线绑定。

此功能只清插件曲线。如果该按钮原本还负责原生计时器/遥测清零，那些仍按模型原来的设置执行。

## 第 11 步：绑定并调节升降提示音

1. 进入 AUDIO / 声音页，选择提示音的按钮/开关和有效位置。
2. 两档开关通常可选“保持有效时”；弹回按钮可选“按下切换”，按一下启用、再按一下关闭。根据自己的使用方式决定。
3. 初始静区可保持 0.3 m/s；地面小幅抬升未超过静区时不响是正常的。
4. 到第 8 页“音量与音调”，先用 Follow radio / 跟随系统或较低档位，不必一开始用最大声音。
5. 需要时调整上升、下降基础音调和慢/标准/快节奏。
6. 保存并退出。设置页面本来会暂停提示音，不在选项列表里自动试听。
7. 在地面确认遥测有效、触发已打开，缓慢改变高度，听上升高音短哔、下降低音长哔。只靠高度估算速度时响应会受传感器更新率限制。
8. 接收机断电后插件提示音应停止；原生失联告警仍应正常。

V16 / X9D / GX12 初次设置默认不绑定按钮，所以刚安装没有哔声是正常的。旧 X9D 的硬件音量效果还需要实机确认，不能把五档菜单当成已经量过响度。

## 第 12 步：调整曲线和 ELRS 回传

1. 曲线窗口先用默认 90 秒，平滑先用默认 0.5 秒，方便核对。
2. 想看更长历史再增加窗口；想更及时看变化可降低平滑，但噪声会更明显。
3. “采样/实际”可能不同，例如 90 秒窗口请求 0.1 秒，实际约 0.75 秒，这是 120 点上限，不是故障。
4. **在控制链路可靠、接收机兼容的前提下，尽可能提高 ELRS 的有效遥测回传频率。** 先记下原有 Packet Rate 与 Telem Ratio，再在地面评估调整。
5. 同一 Packet Rate 下，1:8 比 1:32 有更多遥测时隙，但不是每个时隙都在发 Alt。不要把控制包率直接当成高度更新率。
6. 不使用关闭遥测的 Off；Race 某些状态可能停止遥测。具体菜单取决于 ELRS 版本和接收机能力。
7. 不要在飞行中改 Packet Rate。高包率也不等于更安全，可能减少链路余量；地面调整后做距离/失控保护测试。

插件不会替你改变任何 ELRS 参数。不了解这些设置时，先保持原来的可靠链路配置，阅读[ELRS 官方说明](https://www.expresslrs.org/quick-start/transmitters/lua-howto/#packet-rate-and-telemetry-ratio)再调整。

## 第 13 步：最后验收，暂时不飞

- 重启后模型和混控与安装前一致，插件设置能保存。
- 切换另一个模型，不会自动套用刚才的通道/按钮设置。
- 当前电压与原生同源一致，能区分满充参考。
- 计时器、四/六舵机、模式退出结算符合预期。
- 99% 到 100% 字号不跳，黑白屏总览和舵量都可读。
- Preset 清图、按住空图、松开恢复正确。
- 慢回传不会在每个正常间隔乱闪，真正失联会隐藏失效值并停音。
- 原生告警和失控保护仍正常，与其他常用 Lua 同时运行没有内存/执行错误。

全部地面检查通过后，再由操作者决定受控飞行测试。实验适配不能跳过这一项。

## 出问题时：先做这几件事

| 现象 | 先检查什么 | 不要做什么 |
| --- | --- | --- |
| 电脑没有盘 | 数据线、USB Storage、正确数据接口 | 不要格式化或随意重装驱动 |
| 彩屏找不到 DLGDash | WIDGETS/DLGDash/main.lua 和完整目录层级 | 不要覆盖 MODELS |
| 黑白屏找不到 DLG | SCRIPTS/TELEMETRY/DLG.lua；在 Display 选 Script | 不要去找 Widget |
| 有仪表但全是 -- | 接收机是否供电，原生遥测是否有效 | 不要拿无回传状态判断代码失败 |
| 主屏点 Sail 没反应 | 先进入 Full screen，再点 SET | 普通 Widget 不一定接收触摸 |
| 中文看起来是英文回退/问号 | lang 是否完整、是否系统自定义名称、标签是否太长 | 不要直接重刷中文固件 |
| 字体仍像粘连 | 截图原始像素，检查是否旧版截图/缓存/非整数缩放 | 不要凭压缩图片判断屏幕硬件坏了 |
| 曲线一直空 | 清零源是否一直有效、Alt 是否有数据 | 不要用假高度填满曲线 |
| 电压与万用表不同 | 同时比较原生 RxBt 与插件，必要时用第 10 页记录 | 不要盲目加偏移或先刷接收机 |
| Lua 报错 | 拍全错误、记机型/EdgeTX版本、检查全部文件和缓存 | 不要删掉全部插件或模型 |

## 卸载或恢复旧版

先备份现在的插件配置。彩屏把 DLGDash 从该页面移除或换回原控件；黑白屏把 Display 中的 DLG 脚本取消或恢复之前记录的页面。只移除页面就能停止使用，不必立刻删除文件。

若要回旧版，恢复第 3 步备份中的 DLGDash 目录及对应 profiles，并恢复旧 DLGSetup / DLG 脚本。不要仅恢复旧代码却保留不兼容的新配置。插件回退不需要刷固件，也不需要覆盖全部 MODELS / RADIO。

反馈时请提供：具体遥控器、EdgeTX 版本、页面截图、完整报错、使用四/六舵机、所选电压/高度源以及复现步骤。模型和诊断文件可能包含个人信息，不要直接整盘公开上传。
