# DLGDash v1.0

作者：Sail。首个公开发布版，运行时版本 1.0.0。

## 首批四台

- PA01：320×240 彩屏，主开发机型，保留已有模型插件配置。
- HelloRadio V16：480×272 彩屏，新增实验布局和原生字体检查。
- FrSky X9D 系列：212×64 黑白屏，新增 DLG 遥测脚本。
- RadioMaster GX12：128×64 单色 OLED，新增 DLG 遥测脚本。

V16 / X9D / GX12 仅完成离线接口、绘制和交互测试，尚未实机验收。PA01 本发布版也应地面复验。测试基准 EdgeTX 2.11.3，不承诺 OpenTX。

## 功能

- 主屏作者标签 Sail；保留彩屏全屏 SET 设置入口。
- 大计时器，当前电压 / 满充参考，1S/2S 与 HV 设置。
- 四/六舵机映射及固定字号百分比。
- 从指定模式退出后按延迟结算发射高度，可取阶段峰值。
- 可配置周期与窗口的平滑曲线，正确区分慢包与真正遥测失效。
- Preset 按住清图、松开恢复，升降声音按模型绑定并可调音量/音调/节奏。
- 中英文设置，黑白屏总览与舵量分为两页。
- 完整使用说明、ELRS 遥测回传率注意事项、备份安装脚本和只读电压诊断。

## 升级

下载 DLGDash-v1.0.zip，把 SD 内的内容合并到遥控器内容盘根目录。保留自己的 profiles。黑白屏还需在模型 Display 中选择 Script / DLG；彩屏添加 DLGDash Widget。

2.0.x 是此前内部 PA01 测试编号，本公开版包含其功能与修复，不是回退。旧 DLG2/3/4/5 配置兼容，仅在用户保存时写入当前格式。

安装包不含 MODELS、RADIO、个人 profiles、diagnostics 或固件。插件不自动更改 ELRS 参数，也不校准接收机电压。

## 离线验证

本次四平台自动测试共输出 831 张原生字体/位图渲染图，无文字相互覆盖或屏幕越界；包含 448 个计数断言，另有逐画面和 Lua 接口断言。关键回调的模拟指令检查均低于 20,000。

修正电脑黑白预览的原生字体占位列解码，消除假黑条；中文菜单改为更细的 14 像素行高字形及每屏两项选择。新增可离线阅读的新手逐步安装教程，附正确解码的整数倍放大截图。

安装器在临时目录模拟 PA01、V16、X9D、X9D Plus、X9D Plus 2019、GX12，核对模型/RADIO/profiles 未改、编译缓存有可恢复备份、实验标记和过期备份拒绝逻辑。测试未使用真实遥控器，不代表实机或飞行验收。
